<h2>🎓 Informasi Proyek</h2>
<p>Yayasan Zulka is a digital profile platform for a non-profit foundation, designed to introduce community members, showcase photo galleries of activities, and deliver information interactively. This project was developed as a Capstone Project for the Student Developer track under the Studi Independen Bersertifikat (SIB) Dicoding x IBM program.</p>

<h2>🚀 Key Features & Sections</h2>
<ul>
  <li>Hero Section : A dynamic visual welcome area introducing the foundation's core mission.</li>
  <li>About Section : An in-depth overview of Yayasan Zulka's identity, vision, and values.</li>
  <li>Members : Profiles highlighting key individuals and team members behind the foundation.</li>
  <li>Social Media : Dedicated links connecting visitors to official social channels.</li>
  <li>Gallery : A photo gallery showcasing the foundation's events and community activities.</li>
</ul>

<h2>⚙️ Tech Stack & Implementation</h2>
<p>Built with standard web technologies to ensure lightweight performance, accessibility, and clean maintenance :</p>
<ul>
<li>HTML5 : Provides semantic markup and structured content organization.</li>
<li>CSS3 : Custom styling featuring clean layouts, modern visual elements, and high responsiveness.</li>
<li>JavaScript : Powers interactive navigation, UI animations, and smooth dynamic behavior.</li>
<li>Vercel : Utilized for fast continuous deployment and seamless Git integration.</li>
</ul>
